# Relational N-Back

Updated four-stream relational N-back app.

Included in this build:
- fixed-size 2D grid
- Discord link to `discord.gg/chmr`
- prerecorded Quad Box Natural-Numbers audio (1–8), no TTS
- selectable Position / Sound / Shape / Relation streams
- disabled streams do not render their stimuli
- Variable N with configurable floor
- current per-trial N shown directly above the grid
- response cards directly below the grid
- selectable Circle / Triangle / Square / Pentagon / Hexagon relation shapes
- relation icons based on side-count logic rather than left/right placement
- detailed Wiki explanation for all relation rules

Run tests with:

```bash
npm test
```
