# Relational N-Back

Updated build with:
- fixed-size 2D grid
- Discord link
- pre-recorded digit audio support (`assets/audio/1-8`)
- abstract relation icons based on two-shape logic
- per-stream toggles (position, sound, shape, relation)
- Variable N mode with configurable floor
- shape pool toggles for circle, triangle, square, pentagon, hexagon

## Audio clips
Place files in `assets/audio` using names like:
- `0.mp3` ... `9.mp3`
- or `0.wav` ... `9.wav`
- or `0.ogg` / `0.m4a` ... `9.ogg` / `9.m4a`

Run tests:
```bash
npm test
```
